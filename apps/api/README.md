# FastAPI Backend

`apps/api` это переходный backend-слой для разрезания текущего Flask-монолита на модульную схему.

## Что уже делает слой

- поднимает новый `FastAPI`-контур с OpenAPI на `/api/docs`
- публикует версионированный REST API на `/api/v1`
- проксирует текущие Flask REST-эндпоинты через внутренний bridge, чтобы не переписывать доменную логику одним большим релизом
- держит место под следующий этап миграции realtime-канала

## Текущее решение

Пока бизнес-правила и сторы остаются в `regatta_app/`.
Новый API-слой отвечает за:

- внешнюю версификацию API
- CORS
- typed schema-контракты
- подготовку к отдельному frontend-приложению

## Следующий шаг

Следующий безопасный этап после запуска этого каркаса:

1. вынести room/domain logic из Flask-зависимых модулей в независимые сервисы
2. заменить внутренний proxy-bridge прямыми вызовами сервисов
3. вынести Socket.IO или WebSocket-канал из legacy-слоя в отдельный realtime-модуль FastAPI
