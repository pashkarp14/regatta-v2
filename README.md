# Парусная регата

Flask-only релиз браузерной регаты с обновлённым control deck, комнатами для мультиплеера и Redis-backed sessions.

## Что внутри

- Flask + Flask-SocketIO
- Redis для сессий и хранения комнат
- Совместные комнаты с кодом подключения
- Хост настраивает дистанцию, затем запускает матч
- Во время матча состояние синхронизируется между игроками по очереди хода
- Docker Compose для деплоя одной командой

## Локальный запуск

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py
```

Приложение откроется на `http://127.0.0.1:5001/`.

## Docker Compose

1. Скопируй `.env.example` в `.env` и задай свой `SECRET_KEY`.
2. Запусти:

```bash
docker compose up --build
```

После старта сервис будет доступен на `http://127.0.0.1:5001/`.

## Сценарий комнаты

1. Хост выставляет число лодок и настраивает дистанцию.
2. Хост создаёт комнату и отправляет код остальным игрокам.
3. Игроки подключаются по коду.
4. Когда все места заняты, хост запускает матч.
5. В лобби менять дистанцию может только хост.
6. Во время гонки ходить может только активная лодка; остальные участники видят актуальное состояние в реальном времени.
